# MiniAuth

A lightweight authentication and authorization service
built with ASP.NET Core and .NET 8.

## Features

- JWT authentication
- Refresh token rotation
- Role-based authorization
- Secure password hashing
- Entity Framework Core
- SQL Server
- Docker
- Unit & integration tests
- OpenAPI
- GitHub Actions CI
